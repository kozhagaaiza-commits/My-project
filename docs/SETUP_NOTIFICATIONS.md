# Настройка уведомлений: Telegram-бот и почта

Инструкция для владельца. Всё делается с iPad в браузере и в приложении Telegram, командная строка не нужна.
Без этой настройки сайт работает, но заказы не будут приходить вам в Telegram, а покупатели не получат письма.

## 1. Создать бота в Telegram

1. В Telegram найдите **@BotFather** (синяя галочка рядом с названием) и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Название бота — например, `ForgeCarbon`. Имя бота (username) должно заканчиваться на `bot`, например `forgecarbon_bot`.
4. BotFather пришлёт **токен** вида `123456789:AAH...`. Это пароль от бота: никому его не показывайте и не вставляйте в переписку.
5. Запишите отдельно имя бота без `@` — это `TELEGRAM_BOT_USERNAME`.

## 2. Узнать свой chat id (куда присылать заказы)

1. Найдите в Telegram бота **@userinfobot** и нажмите «Запустить».
2. Он ответит числом в строке `Id` — это ваш chat id (например, `512398764`).
3. Затем откройте **своего** бота (из шага 1) и нажмите «Запустить» или отправьте любое сообщение. Пока вы не написали боту первым, он не сможет написать вам.

## 3. Пароль приложения Яндекс Почты (для писем покупателям)

1. Войдите в Яндекс ID ящика, с которого пойдут письма (например, `orders@forgecarbon.ru`).
2. Откройте «Безопасность» → «Пароли приложений» (или id.yandex.ru/security/app-passwords).
3. Создайте пароль для типа «Почта» (IMAP/SMTP), название — `ForgeCarbon`. Яндекс покажет пароль один раз — скопируйте его.
4. В настройках почты (Почта → Настройки → Почтовые программы) должен быть включён доступ «С сервера imap.yandex.ru» / по протоколу SMTP.
5. Обычный пароль от ящика не подходит — только пароль приложения.

## 4. Переменные в Vercel

Vercel → ваш проект → Settings → Environment Variables. Добавьте для окружения Production:

| Переменная | Что вписать |
|------------|-------------|
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_BOT_USERNAME` | имя бота без `@`, например `forgecarbon_bot` |
| `TELEGRAM_WEBHOOK_SECRET` | случайная строка 32–64 символа из букв, цифр, `_` и `-` (см. ниже) |
| `TELEGRAM_ADMIN_CHAT_ID` | ваш chat id из шага 2 |
| `SMTP_USER` | адрес ящика Яндекса, например `orders@forgecarbon.ru` |
| `SMTP_PASSWORD` | пароль приложения из шага 3 |

`SMTP_HOST` (`smtp.yandex.ru`) и `SMTP_PORT` (`465`) уже заданы в списке переменных проекта.

**Как получить `TELEGRAM_WEBHOOK_SECRET`.** Любой генератор паролей: длина 40, только буквы и цифры (без пробелов и спецсимволов, кроме `_` и `-`). Например, в приложении «Пароли» на iPad создайте надёжный пароль и уберите из него лишние символы. Сохраните его: он понадобится ещё раз на шаге 5.

После добавления переменных сделайте **Redeploy** последнего деплоя (Deployments → три точки → Redeploy), иначе сайт не увидит новые значения.

## 5. Зарегистрировать webhook (чтобы бот отвечал)

Откройте в браузере Safari одну ссылку, подставив свои значения (без угловых скобок):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=<АДРЕС_САЙТА>/api/webhooks/telegram&secret_token=<СЕКРЕТ>&allowed_updates=["message"]
```

Пример структуры: `https://api.telegram.org/bot123456789:AAH.../setWebhook?url=https://forgecarbon.vercel.app/api/webhooks/telegram&secret_token=abc...&allowed_updates=["message"]`

- `<ТОКЕН>` — токен бота, `<АДРЕС_САЙТА>` — адрес сайта с `https://` и без слэша в конце, `<СЕКРЕТ>` — значение `TELEGRAM_WEBHOOK_SECRET`.
- Ответ `{"ok":true,"result":true,"description":"Webhook was set"}` означает успех.
- **Токен в этой ссылке секретный.** Не отправляйте ссылку никому, не публикуйте скриншот, после регистрации очистите историю Safari (Настройки → Safari → Очистить историю). Если ссылка попала не туда — перевыпустите токен в @BotFather командой `/revoke` и обновите `TELEGRAM_BOT_TOKEN` в Vercel.
- Проверить регистрацию: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` — в ответе должен быть ваш адрес и `"pending_update_count":0` без `last_error_message`.
- Если токен или секрет поменяли — зарегистрируйте webhook заново.

## 6. Проверка

1. Напишите своему боту любой текст. Он ответит «Передал инженеру. Ответим в рабочее время»: сообщение дошло до сайта. (Как администратор вы получите это сообщение без пересылки самому себе — это нормально: из чата админа сообщения не пересылаются.) Для проверки напишите боту с другого аккаунта Telegram: вам придёт пересланное сообщение.
2. Оформите тестовый заказ и оплатите его (см. чек-лист запуска, Приложение B Чертежа, заказ на 1 ₽).
3. После оплаты: вам в Telegram приходит «💳 Оплачен заказ …», покупателю на почту — письмо «Заказ … оплачен». Письмо приходит в течение минуты.
4. На странице заказа нажмите «Получать статусы в Telegram» → бот ответит «Подписка на заказ … оформлена». Команда `/stop` отключает уведомления.

Если что-то не пришло, сообщения не теряются: сайт повторит отправку по расписанию (через 5 минут, 30 минут, 2 часа, 12 часов; после 5 неудач — перестанет). Заказы всегда видны в админке.

## Чего НЕ делать

- Не вставлять токен бота, пароль приложения и секрет webhook в чаты, письма, скриншоты и в код. Они хранятся только в Vercel.
- Не использовать обычный пароль от почты вместо пароля приложения.
- Не менять `TELEGRAM_WEBHOOK_SECRET` без повторной регистрации webhook (шаг 5): иначе Telegram будет получать ответ 403 и бот замолчит.
- Не удалять и не блокировать собственного бота в Telegram: уведомления админу перестанут приходить.
- Не менять `ORDER_TOKEN_SECRET` после запуска: перестанут открываться все ссылки на заказы из писем.
- Не публиковать ссылку на `/api/webhooks/telegram` в виде «вручную проверить»: открыть её в браузере нельзя (только POST от Telegram).
